# Toshi.bet Social Club

The members' site for the Toshi.bet Social Club: velvet-curtain opening, the creed, the House, the four-step initiation (petition, Toshi.bet sign-in via `toshi.bet/r/mariannehere`, temperament reading, card) and the metal card atelier.

It is a static site with no build step: `index.html` plus `crest.webp`. On Vercel, import the repo with the framework preset set to **Other** and leave the build command empty.

Applications are kept in each visitor's browser for now. Collecting them centrally needs a small backend (for example Vercel Blob or Supabase).
